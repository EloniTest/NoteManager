# NoteManager 📝

**NoteManager** — это настольное приложение для управления заметками, написанное на C++. Приложение позволяет создавать, просматривать, обновлять и удалять заметки с сохранением в локальную базу данных SQLite.

---

## 📋 Возможности

- ✅ **Создание заметок** — добавление новых заметок с названием и содержимым
- ✅ **Просмотр всех заметок** — вывод всех сохраненных заметок
- ✅ **Обновление заметок** — редактирование существующих заметок
- ✅ **Удаление заметок** — удаление ненужных заметок
- ✅ **Автоматические временные метки** — каждая заметка содержит дату создания
- ✅ **Локальное хранилище** — все данные хранятся в SQLite БД

**В разработке:**
- 🔄 Напоминания о заметках
- 📂 Категоризация заметок
- 🔍 Поиск по заметкам

## 🏗️ Архитектура приложения

### Классы и их назначение:

#### **Database** (`include/Database.h`, `src/Database.cpp`)
Отвечает за подключение и управление БД:
- `Database(const std::string& fileName)` — конструктор, открывает БД
- `getConnection()` — возвращает указатель на соединение SQLite
- `isOpen()` — проверяет открыта ли БД
- `~Database()` — деструктор, закрывает БД

```cpp
Database db("notes.db");
sqlite3* connection = db.getConnection();
```

#### **Notes** (`include/Notes.h`, `src/Notes.cpp`)
Работает с логикой заметок:
- `Notes(sqlite3* database)` — конструктор, инициализирует таблицу
- `addNote(title, content)` — добавляет новую заметку
- `getAllNote()` — возвращает все заметки в виде `std::vector<Note>`
- `updateNote(id, title, content)` — обновляет заметку по ID
- `removeNote(id)` — удаляет заметку по ID

```cpp
Notes notes(db.getConnection());
notes.addNote("Мой день", "Важные дела");
auto allNotes = notes.getAllNote();
notes.updateNote(1, "Обновленная заметка", "Новое содержимое");
notes.removeNote(1);
```

#### **Note** (`include/Notes.h`)
Структура данных для одной заметки:
```cpp
struct Note {
    int id;                    // Уникальный идентификатор
    std::string title;         // Название заметки
    std::string content;       // Содержимое заметки
    std::string created_at;    // Дата и время создания
};
```

## 💾 База данных

### Схема таблицы `notes`:

```sql
CREATE TABLE notes (
    id INTEGER PRIMARY KEY AUTOINCREMENT,  -- Автоматический ID
    title TEXT NOT NULL,                   -- Название (обязательное)
    content TEXT NOT NULL,                 -- Содержимое (обязательное)
    created_at TEXT NOT NULL               -- Дата создания (UTC)
);
```

**Файл БД**: `data/notes.db` создается автоматически при первом запуске.

## ⚠️ Известные проблемы и решения

### Проблема: Ошибка "no such table: notes"
**Решение**: Таблица создается автоматически при первом запуске. Если проблема сохраняется, удалите файл `data/notes.db` и запустите приложение снова.

### Проблема: Русский текст отображается неправильно
**Решение**: Приложение уже настроено на UTF-8 для Windows (через `SetConsoleOutputCP`).

### Проблема: БД файл не создается
**Решение**: Убедитесь, что существует папка `data/` в корне проекта и у вас есть права на запись.

## 📝 Примеры кода

### Минимальный пример использования:

```cpp
#include "Database.h"
#include "Notes.h"
#include <iostream>

int main() {
    // Создание БД
    Database db("notes.db");
    if (!db.isOpen()) {
        std::cerr << "Ошибка открытия БД\n";
        return 1;
    }

    // Инициализация Notes
    Notes notes(db.getConnection());

    // Добавление заметки
    notes.addNote("Важно", "Не забыть купить хлеб");

    // Вывод всех заметок
    auto allNotes = notes.getAllNote();
    for (const auto& note : allNotes) {
        std::cout << "ID: " << note.id << "\n";
        std::cout << "Название: " << note.title << "\n";
        std::cout << "Содержимое: " << note.content << "\n";
        std::cout << "Создано: " << note.created_at << "\n\n";
    }

    return 0;
}
```
